# Kryp

## Dev instructions

### Getting started

1. Install [Node.js](https://www.meteor.com/install) (12+)
2. Run `npm install`

### Commands

- `npm run dev`: Start in dev mode
- `npm run build`: Build
- `npm run preview`: Preview production app

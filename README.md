# Kryp

## Dev instructions

### Getting started
1. Install [Meteor](https://www.meteor.com/install) (1.11.1 or later)
2. Install npm if you'd like to run `npm` commands. Otherwise, you can use `meteor npm`

### Commands

Build `kryp-calculator`:
```
npm run build
```

Start:
```
meteor
```

Connect to the local database:
```
meteor mongo
```
